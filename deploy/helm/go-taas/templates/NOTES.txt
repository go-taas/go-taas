namespace "{{ .Values.controller.config.controller.namespace }}"; the
model-weights PersistentVolumeClaim is created there on first use from the
StorageClass "{{ .Values.controller.config.controller.weights.storageClass | default "<cluster default>" }}".

{{- if not .Values.controller.config.controller.weights.storageClass }}

NOTE: controller.config.controller.weights.storageClass is empty, so the
shared model-weights PVC is provisioned from the cluster's default
StorageClass. Inference pods and the control plane must read the same model
weights, which requires a ReadWriteMany-capable (e.g. JuiceFS-backed)
StorageClass shared by both.
{{- end }}
